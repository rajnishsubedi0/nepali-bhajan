# 🕉️ Nepali Bhajan

An app for Nepali devotional songs (bhajans), bringing lyrics and YouTube video links together in one place so they are easy to find, read, and enjoy.

---

## 📖 About

Bhajans are an important part of Nepali spiritual and cultural life. This project aims to:

- Preserve traditional and popular Nepali bhajans
- Make lyrics easily accessible for singing and learning
- Link each bhajan to its YouTube video so you can listen and watch

## ✨ Features

- Bhajan lyrics in Nepali (Devanagari)
- Bhajans categorized by deity, so you can quickly find the ones you are looking for
- Save your favorite bhajans for quick access
- YouTube video links for each bhajan (no audio files are stored in the app)
- Search or browse for bhajans

## 🎵 Listening

This app does not host any audio. Each bhajan includes a link that opens the video on YouTube, so all audio and video remain with their original creators.

## 🤝 Contributing

Contributions are welcome! To add a bhajan or fix a mistake:

1. Fork this repository
2. Create a branch: `git checkout -b add-new-bhajan`
3. Add or edit the bhajan (include the title, lyrics, deity category, and YouTube link)
4. Commit: `git commit -m "Add [bhajan name]"`
5. Push: `git push origin add-new-bhajan`
6. Open a Pull Request

**Guidelines**
- Use UTF-8 encoding for Nepali text
- Check the spelling of lyrics before submitting
- Make sure YouTube links work and point to the correct bhajan

## ⚠️ Disclaimer

Many bhajans are traditional or have unknown authorship. Videos linked here belong to their respective creators and channels on YouTube. If you are a rights holder and want something credited or removed, please open an issue or contact the maintainer.
